This is an English-language localization mod for World of Warships; it is intended for use with AndrewTaro's LocalizationLoader mod, available here: https://github.com/AndrewTaro/LocalizationLoader

# What Precisely the Mod Changes:
* The "COLLISION" indicator that displays when the player's ship crashes into an island has been replaced with "ALLISION".
* The name of the "Collision Avoidance System" setting under the Battle tab has been changed to "Allision Avoidance System".

# How to Install:
1. Install the LocalizationLoader; instructions on how to do so can be found in that repository's README.
2. Within the game's ``bin\<wows_version>\res_mods`` directory, create a ``texts\en`` directory (if one does not already exist).
3. Place this repository's ``Allision.mo`` file into the aforementioned ``en`` folder.
4. Done!

# How to Uninstall:
1. Delete the ``Allision.mo`` file from ``bin\<wows_version>\res_mods\texts\en``.
2. Done!
